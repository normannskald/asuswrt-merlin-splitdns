# Changelog

All notable changes to this project will be documented in this file.
This project adheres to [Semantic Versioning](https://semver.org/).

## [v1.2.0] — 2026-10-29

### 🇷🇺 Русский
- **Добавлен блок «Профили DNS»**: возможность создавать неограниченное число апстрим-профилей с модальным окном добавления, поддержкой IPv4, IPv6, портов и готовыми пресетами популярных DNS-провайдеров.
- **Фикс таблицы с правилами**: поля ввода правил расширены до многострочных с гибкой валидацией любых разделителей.
- **Фикс диагностики резолвинга**: фоновый запуск теста резолвинга без перезагрузки веб-страницы.
- **Фикс интерфейса**: перемещение блока настроек в нижнюю часть страницы и добавление копирайта проекта.

### 🇬🇧 English
- **Added DNS Profiles block**: ability to configure multiple upstream profiles via modal dialog with IPv4, IPv6, port support, and popular presets.
- **Rules table fix**: multiline fields for domains and comments with flexible delimiter parsing.
- **Resolution diagnostics fix**: silent background execution without page reload.
- **UI fix**: moved settings block to bottom and added copyright footer.

---

## [v1.1.0] — 2026-10-28

### 🇷🇺 Русский
- **Обновлённый интерфейс**: дизайн таблицы правил, диагностики и управления настройками приведён в соответствие со стилем прошивки Asuswrt-Merlin.
- **Удобные пресеты**: кнопки быстрой подстановки национальных зон и госсервисов прямо над таблицей правил.
- **Управление правилами**: добавлено редактирование строк и изменение приоритета перетаскиванием (Drag-and-Drop).

### 🇬🇧 English
- **Redesigned Web UI**: rules table, diagnostics, and settings management aligned with Asuswrt-Merlin styling.
- **Quick-Fill Presets**: one-click buttons for national zones and government services above the rules table.
- **Rule Management**: added in-place editing and drag-and-drop rule priority reordering.
